# IA II - Guías reconstruidas

Proyecto sencillo en Python, organizado por guía y revisado contra los 6 documentos originales.

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

Ejecute una guía a la vez:

```bash
python guia1.py
python guia2.py
python guia3.py
python guia4.py
python guia5.py
python guia6.py
```

Las guías 2 a 6 pueden trabajar con una imagen propia. Si no se encuentra la imagen esperada, el programa crea una imagen de demostración automáticamente para que pueda ejecutarse sin descargar archivos.

Puede reemplazar las imágenes de la carpeta `imagenes` por fotografías propias para obtener resultados reales.

Los resultados se guardan en `resultados`.
